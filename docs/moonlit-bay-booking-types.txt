HOW TO READ THIS FILE
---------------------
Every line is tagged so you never mistake research for invention:

  [VERIFIED]  Sourced from a public listing. URL in the SOURCES section.
  [MARKET]    A real going rate for this activity in the Weligama/Mirissa
              area, from published operator pricing. Not Moonlit Bay's own
              price - they may charge differently.
  [PROPOSED]  Designed by me for this system. NOT a real Moonlit Bay
              offering. Confirm with the owner before publishing.

This follows the rule already written into docs/tourism-business-template.md
section 3: "Don't fabricate a plausible-looking rating for a real,
identifiable business - leave it unset if unknown." Moonlit Bay is a real
business, so its packages are marked [PROPOSED], not presented as fact.

2. ARCHETYPE MAPPING (per docs/tourism-business-template.md)
================================================================================

Primary archetype: H. Homestay / eco-lodge
  Resource.Category = Room
  BookingType.BookingUnit = "Night"
  One Resource row per room (3 rows).

Secondary (activities): archetype B (instructor-led) and A (fixed-departure
excursion), only if Moonlit Bay actually sells them. If they merely refer
guests to a surf school, DO NOT create these booking types - an unbookable
booking type is worse than none.

Package archetype: F. Multi-day package
  BookingUnit = "Package", RequiresApproval = true
  Note the known limitation in section 6 of the template doc: a true
  multi-resource package is not modelled. Each package below is therefore
  one Resource of Category=Other representing "the package", with the
  itinerary carried in ConfigJson. That is the documented simplification,
  not an oversight.

================================================================================
6. SANITY CHECKS BEFORE YOU SEED
================================================================================

1. CAPACITY. Three rooms, ~6 guests total. MaxParticipants on any package
   must never exceed what the rooms hold. PKG-2 at 4 people already needs
   two of the three rooms.

2. THE ROOM RATE IS AN ASSUMPTION. LKR 4,000 sits mid-range of the
   published LKR 2,823-6,333. Every package total above is arithmetic on
   that one number - change it and all five totals move. Get the real rate
   first if you can.

3. FOREIGNER vs LOCAL PRICING. The whale-watching figures are the foreign
   tourist rate. Sri Lankan operators very often run a separate, much lower
   local rate. If this platform serves both, that is a real modelling gap -
   and note the template doc already flags that per-ticket-type pricing
   (adult vs child in one booking) is NOT natively supported.

4. ACTIVITIES MAY NOT BE THEIRS. Nothing found confirms Moonlit Bay runs
   surf lessons, whale trips or cooking classes. A small guesthouse
   typically refers guests to neighbours. Only create BT2-BT7 for what they
   genuinely sell and can be held accountable for.

5. THE COOKING CLASS PRICE IS INVENTED. LKR 4,500 is a placeholder, flagged
   again here because it feeds PKG-4 and PKG-5.

6. SEASONALITY IS REAL. Whale watching is Nov-Apr on this coast. Weligama's
   surf works year-round, which is exactly why the surf packages are the
   safer year-round product and the whale package is not.
